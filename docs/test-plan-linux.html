Compressarr Linux test plan

How to use this

Work through the sections on the dedicated Linux test machine, running the program from a terminal so you can see what it prints. For each test mark Pass, Fail, Blocked (couldn't run it) or N/A, and write a note for anything that isn't a clean pass - what you saw and any file name involved. Copy results (Markdown) at the top gives text to paste back into the chat; Save results file keeps your progress.

Already seen working (first test, Ubuntu 26.04.1): unpacking and starting the program, the web interface, the tray icon and its menu (B1, B2), and HandBrake encodes of several files (E3). Mark those quickly. Known gaps are written in the tests as Known gap: for those, a "pass" means the program behaves the way the test says, and your notes are what we use to decide the work. Section L is for the official release and stays Blocked until the .deb and the Linux defaults exist.

Machine

Set-up on the test machine

  • sudo apt install handbrake-cli ffmpeg (Ubuntu/Debian names; use your distribution's equivalents), then set the paths in Settings and on the Encoder page.
  • Make a scratch area: /srv/test/in, /srv/test/out, /srv/test/lib/TV Shows, /srv/test/lib/Movies (or anywhere you own).
  • Test media: a few 10-30 second clips (H.264 1080p with two audio tracks and subtitles, an HDR10 HEVC clip, a Dolby Vision clip if you have one, an interlaced clip, a truncated copy of a good file), plus an .srt named like one of them.
  • Optional: an NFS or SMB share, a second disk or small tmpfs, a reachable Sonarr/Radarr, a Slack/Discord webhook.

If something fails, collect

  • The terminal output of ./Compressarr.Desktop, the relevant lines from the Live Log (use View Log - Copy all), and the run's log in ~/.config/Compressarr/Logs.
  • For an encode problem: the file's detail log (*_HBdetails.txt or *_FFdetails.txt) and the HTML report.
  • Distribution and version (cat /etc/os-release), the desktop and session type (echo $XDG_CURRENT_DESKTOP $XDG_SESSION_TYPE), and your compressarr.settings.json with API keys and webhooks removed.
