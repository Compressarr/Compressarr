Compressarr 2.2 test plan

How to use this

Work through the sections on the new test machine. For each test mark Pass, Fail, Blocked (couldn't run it) or N/A, and write a note for anything that isn't a clean pass - what you saw, and any file name involved. Your answers are saved in this browser automatically. When you're done (or want to stop for the day) press Copy results (Markdown) and paste it back to me, or Save results file and send that; we'll then go through the failures together. P1 tests are the must-run ones, P2 should-run, P3 nice to have.

Highest-risk area: ffmpeg has only been exercised against stand-in programs in the automated tests - the first encodes with a real ffmpeg happen on your test machine. Sections E, H and B (ffmpeg parts) are where surprises are most likely. HandBrake behaviour is covered by the existing test suite, but sections A, C, D and G check that the new profile system didn't change it.

Machine and builds

Test media worth collecting first

  • M1 - ordinary 1080p H.264 MKV with an English AC3 5.1 track, a French AC3 track, English and French text subtitles, and chapters.
  • M2 - 4K HDR10 HEVC rip (mastering-display data) with TrueHD/Atmos 7.1 + an AC3 compatibility track, English PGS subtitles.
  • M3 - interlaced source (DVD rip / broadcast .ts, 480i or 1080i), MPEG-2 or H.264.
  • M4 - letterboxed film (visible black bars top/bottom).
  • M5 - Dolby Vision file (profile 5 or 8) - and, if you can find one, M6 an HDR10+ file.
  • M7 - MP4 with mov_text subtitles. M8 - file with no audio. M9 - MKV with cover art attached. M10 - audio track with no language tag.
  • M11 - anime-style MKV with ASS subtitles and embedded fonts. M12 - file with a very long name and unicode characters.
  • M13 - a truncated copy of M1 (cut a MKV to about half its bytes, e.g. fsutil file createnew isn't right - use a hex editor, or copy the first half with PowerShell [IO.File]::ReadAllBytes/WriteAllBytes). Used to provoke ERROR 111.
  • Also handy: MediaInfo (or ffprobe) to inspect results, and VLC/Plex/Jellyfin to confirm playback.

If something fails, collect

  • The relevant lines from the Recent log on the Monitor page, and the run's log file in %AppData%\Compressarr\Logs.
  • For an encode problem: the file's detail log (*_HBdetails.txt for HandBrake, *_FFdetails.txt for ffmpeg - it starts with the profile, every track decision, and the exact command) and the HTML report from %AppData%\Compressarr\Reports.
  • A screenshot, and your %AppData%\Compressarr\compressarr.settings.json (remove API keys/webhooks first) and Profiles\ folder when profiles are involved.
