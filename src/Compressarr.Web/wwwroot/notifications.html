Receive Digest: at on at

A periodic toast summarizing recent activity ("Compressed N files, reducing original size from X GB to Y GB, saving Z% of original size") instead of, or alongside, the per-run toast above.

Message Format

Controls the Title/message text sent to Discord, Slack, Telegram, Pushover, ntfy, Gotify, and Notifiarr when a run completes. Doesn't affect the desktop toast above or the Generic Webhook's raw data payload.

Tokens: {run_number} {files} {saved_gb} {saved_pct} {before_gb} {after_gb} {duration} {outcome} {error_count} {warning_count} {retries_succeeded} {report_path} {today_files} {today_saved_gb} {month_files} {month_saved_gb} {year_files} {year_saved_gb} {file_list} {machine}

{file_list} is the filename(s) processed this run, one per line - the only token that can include a media filename. It's left out of every built-in style on purpose; only include it here if you're comfortable with this channel's destination seeing your filenames.

{machine} is the machine name below, and is empty unless Include machine name is ticked. Put it wherever you want it in the title or body.

For when you run Compressarr on more than one machine: the Minimal, Standard and Detailed styles start their title with it, e.g. [Basement NAS] Compressarr run #47 - Success, and so do digests and the Test button. A Custom style places it with {machine} instead. The Generic Webhook gets it as its own machine field. Off by default; it is only sent once you tick this and save.
