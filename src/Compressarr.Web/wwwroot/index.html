Web UI

Install Compressarr as a standalone app, with its own icon and no browser chrome - useful on a phone or tablet, or for one-tap access on desktop.

To install on iPhone/iPad: tap the Share icon in Safari, then "Add to Home Screen". iOS doesn't let a page trigger this directly.

Compressarr is installed as an app in this browser. There's no button a page can offer to remove it - browsers deliberately keep that control with you, not the site. To uninstall: open chrome://apps (or edge://apps), right-click Compressarr, and choose Uninstall/Remove.

Updates

Beta builds are test versions: they have the newest features and can have bugs. Choosing Stable and beta shows the newest version of either kind as an update.

Announcements

Compressarr checks GitHub once a day for these, and nothing about you or your computer is sent. Turn off to disable.
