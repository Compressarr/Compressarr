HandBrake

HandBrake's presets are no longer set up here. Compressarr always uses its own profiles (built-ins plus yours), managed on the Profiles page - where you can also import presets from the HandBrake app or a presets file. There is no presets.json path or Install/Merge step any more.

ffmpeg Experimental

An optional second encoder. A lane uses it only if you pick ffmpeg as that lane's encoder on the Lanes page - until then nothing changes. ffmpeg won't produce byte-identical output to HandBrake, and Dolby Vision / HDR10+ files are handed to HandBrake automatically (see the ffmpeg profile's fallback).
