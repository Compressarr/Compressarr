Queue priority

When a file first arrives, a rule places it ahead of (Higher) or behind (Lower) the files that are waiting. Files of the same level keep their arrival order, a file you move by hand stays where you put it, and the file being encoded always finishes first. A rule matches when the show or movie title contains the text, or when the file or its folder carries that TMDb id, for example {tmdb-1396}. The first matching rule wins.
